# Frontend Components

This directory contains reusable visual blocks and user interface elements that are shared across different views and pages.

* **[`Navbar.jsx`](file:///Users/sakshamtripathi/Desktop/Real%20Estate/ev-management/src/components/Navbar.jsx)** - Application top navigation bar featuring role-based menu options (Visitor, Employee, Owner) and user session/auth actions.
* **[`Footer.jsx`](file:///Users/sakshamtripathi/Desktop/Real%20Estate/ev-management/src/components/Footer.jsx)** - Bottom page footer displaying branding, information links, and standard copyright text.
* **[`Hero.jsx`](file:///Users/sakshamtripathi/Desktop/Real%20Estate/ev-management/src/components/Hero.jsx)** - Eye-catching introductory dashboard layout with search/filter widgets for real estate listings.
* **[`ListingForm.jsx`](file:///Users/sakshamtripathi/Desktop/Real%20Estate/ev-management/src/components/ListingForm.jsx)** - The input and validation handler for adding/editing property details (prices, location, type, and image uploads).
* **[`ProtectedRoute.jsx`](file:///Users/sakshamtripathi/Desktop/Real%20Estate/ev-management/src/components/ProtectedRoute.jsx)** - Navigation wrapper checking authentication state and blocking unauthorized users from accessing sensitive employee/owner dashboards.
