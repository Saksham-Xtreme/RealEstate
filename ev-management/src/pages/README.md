# Frontend Pages

This directory holds the main view configurations, each mapped to a specific path using client-side routing.

## Main Pages

* **[`Landing.jsx`](file:///Users/sakshamtripathi/Desktop/Real%20Estate/ev-management/src/pages/Landing.jsx)** - Homepage displaying featured property catalogs, filters, and standard call-to-actions.
* **[`Authentication.jsx`](file:///Users/sakshamtripathi/Desktop/Real%20Estate/ev-management/src/pages/Authentication.jsx)** - Single sign-on, login, and registration screen with JWT management.
* **[`Listing.jsx`](file:///Users/sakshamtripathi/Desktop/Real%20Estate/ev-management/src/pages/Listing.jsx)** - List view showing properties matching active filters, categories, and categories (Buy / Rent).
* **[`ListingDetail.jsx`](file:///Users/sakshamtripathi/Desktop/Real%20Estate/ev-management/src/pages/ListingDetail.jsx)** - Individual property detail page showing full specifications, images, and visitor inquiry trigger buttons.
* **[`MyInterests.jsx`](file:///Users/sakshamtripathi/Desktop/Real%20Estate/ev-management/src/pages/MyInterests.jsx)** - Personalized user panel listing saved properties, inquiry logs, and tracking status.
* **[`ErrorPage.jsx`](file:///Users/sakshamtripathi/Desktop/Real%20Estate/ev-management/src/pages/ErrorPage.jsx)** - Fallback 404 handler for missing routes.
