# Custom Hooks

This folder holds custom React hooks encapsulating state logic, lifecycle management, and API integrations.

## Core Hooks

* **Session & Idle Tracking** - Automatically monitors user keyboard activity and mouse movements, transmitting active pings to the server at specified intervals.
* **Lead Analytics Tracker** - Hooks into page views and click events to gather user session time metrics, supplying client interaction data utilized by the server's lead scoring module.
