# MongoDB Data Models

This directory defines Mongoose schemas representing database collections.

## Schema Models

* **[`user.model.js`](file:///Users/sakshamtripathi/Desktop/Real%20Estate/server/src/models/user.model.js)** - User records, passwords, and permissions (User / Employee / Owner).
* **[`employee.model.js`](file:///Users/sakshamtripathi/Desktop/Real%20Estate/server/src/models/employee.model.js)** - Employee details, performance ratings, and assigned properties.
* **[`listing.model.js`](file:///Users/sakshamtripathi/Desktop/Real%20Estate/server/src/models/listing.model.js)** - Properties catalogs (description, locations, prices, pictures, and type).
* **[`society.model.js`](file:///Users/sakshamtripathi/Desktop/Real%20Estate/server/src/models/society.model.js)** - Local community/neighborhood context files.
* **[`interest.model.js`](file:///Users/sakshamtripathi/Desktop/Real%20Estate/server/src/models/interest.model.js)** - Connects users to listings when they express purchase/rent interest.
* **[`analytics.model.js`](file:///Users/sakshamtripathi/Desktop/Real%20Estate/server/src/models/analytics.model.js)** - Analytics storage for active time logs and tracking histories.
